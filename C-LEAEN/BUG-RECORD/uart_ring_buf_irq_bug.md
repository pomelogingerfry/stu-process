# 串口环形缓冲+中断bug记录
## Bug1
现象：偶尔丢数据、乱码
排查：加大缓存没用，看指针发现主循环读的时候，中断同时在改指针
原因：共享指针没保护，抢数据了
解决：读指针的时候临时关掉串口中断
收获：中断和主循环共用的变量要保护

## Bug2
现象：缓存满了之后，新数据直接盖掉旧的
原因：判满写错了，分不清空和满
解决：用(wr+1)%长度==rd判断满，满了就丢掉新数据
收获：环形缓冲要留一个空位用来区分空和满

## Bug3
现象：一收到数据程序卡死
原因：中断里面写了printf，printf会阻塞
解决：中断只存数据，打印放到主循环
收获：中断里不能放printf、延时这类东西
